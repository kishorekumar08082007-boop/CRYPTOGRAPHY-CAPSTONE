# Digital Certificate & Document Signature Verification System

A complete, working, localhost-based web application implementing digital document signing and verification using RSA-2048 with RSA-PSS and SHA-256.

> **Academic Notice**: This system uses self-signed certificates for demonstration purposes only. It is **not** backed by a trusted Certificate Authority (CA) and should not be used in production environments.

---

## Features

| Module | Description |
|--------|-------------|
| **User Auth** | Registration, login, session management, role-based access (user / admin) |
| **Certificate Mgmt** | RSA-2048 key pair generation, self-signed certificate, expiry tracking |
| **Document Signing** | PDF upload, SHA-256 hashing, RSA-PSS signature, QR code generation |
| **Verification** | Tamper detection via hash comparison, RSA-PSS signature verification |
| **History** | Verification attempt log with GREEN/RED/ORANGE status |
| **Admin Panel** | User management, certificate revocation, system statistics |

---

## Technology Stack

- **Backend**: Python 3.12, Flask 3.0
- **Database**: MySQL 8.0
- **Cryptography**: `cryptography` library — RSA-2048, RSA-PSS, SHA-256, Fernet (private key encryption at rest)

## Installation — Step by Step

### Step 1 — Clone / extract the project

Place the `digital_signature_system/` folder anywhere, e.g. `C:\Users\yourname\k.project\digital_signature_system\`

### Step 2 — Install Python dependencies

Open PowerShell in the project folder:

```powershell
py -m pip install -r requirements.txt
```

### Step 3 — Run the interactive setup script

```powershell
py setup_db.py
```

The script will:
1. Ask for your MySQL credentials
2. Create the `digital_signature_system` database and all tables
3. Generate a Fernet encryption key for private key storage
4. Generate a Flask secret key
5. Ask for your admin account email and password
6. Write a `.env` file with all configuration

### Step 4 — Start the application

```powershell
py app.py
```

Open your browser at: **http://localhost:5000**

## Security Design

| Concern | Implementation |
|---------|---------------|
| Password storage | PBKDF2-HMAC-SHA256 with 600,000 iterations (Werkzeug) |
| Private key storage | Fernet symmetric encryption at rest; key from environment variable |
| Private key exposure | Never sent to browser — all signing on server |
| SQL injection | Parameterized queries via `mysql-connector-python` |
| CSRF | Flask-WTF CSRF protection on all POST forms |
| File upload | Extension whitelist (PDF only), 16 MB limit, UUID-prefixed storage names |
| Access control | `@login_required` and `@admin_required` decorators |
| Session | Flask server-side sessions with signed cookie |
| Config secrets | Loaded from `.env` via `python-dotenv` |

## Verification Status Reference

| Status | Color | Meaning |
|--------|-------|---------|
| **VALID** | 🟢 Green | SHA-256 matches + RSA-PSS signature verified |
| **TAMPERED** | 🟠 Orange | SHA-256 hash mismatch — document was modified after signing |
| **INVALID** | 🔴 Red | RSA-PSS signature verification failed (corrupted, wrong key, etc.) |

## Cryptographic Implementation Notes

1. **Key Generation**: `rsa.generate_private_key(public_exponent=65537, key_size=2048)` — standard RSA-2048
2. **Signing**: `private_key.sign(file_bytes, PSS(MGF1(SHA256), MAX_LENGTH), SHA256())` — RSA-PSS with SHA-256
3. **Verification**: `public_key.verify(signature, file_bytes, PSS(...), SHA256())` — raises `InvalidSignature` on failure
4. **Private key at rest**: Fernet (AES-128-CBC + HMAC-SHA256) — encrypted file stored in `keys/` directory
5. **Hash**: `hashlib.sha256(file_bytes).hexdigest()` — 64-character hex string

All cryptographic operations use the Python `cryptography` library — no custom or manual crypto implementations.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `ModuleNotFoundError` | Run `py -m pip install -r requirements.txt` |
| `Connection refused` MySQL | Make sure MySQL service is running: `net start MySQL80` |
| `PRIVATE_KEY_ENCRYPTION_KEY not set` | Run `py setup_db.py` to generate `.env` |
| `Certificate not found` | Go to My Certificate page → Generate Certificate |
| Port 5000 in use | Change port in `app.py` last line: `port=5001` |
